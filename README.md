# SnagWise theme

Shopify theme for **SnagWise** (snagwise.myshopify.com): brand-new, sealed, name-brand products under retail, with local pickup and delivery in the GTHA and Waterloo Region.

Fork of Shopify Dawn 16.0.0 with the shared conversion layer used across the Bello-online stores (`trust-bar`, `testimonials`, `comparison-table`, `stats-strip` sections, `sticky-atc` and `free-shipping-bar` snippets, `assets/cro.css`). Brand design and SnagWise-specific sections are added on top; see the commit history.

The repository is connected to the store through Shopify's GitHub integration: pushes to `main` sync to the theme in the store's theme library.
